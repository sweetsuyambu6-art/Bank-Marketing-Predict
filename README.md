### Banking Marketing Analysis and Prediction Dashboard

This project is an interactive banking marketing analytics dashboard developed using Python and Streamlit. It analyzes customer demographics, bank balances, loan information, contact details, and marketing campaign data through interactive tables and visualizations. It also implements multiple machine learning classification algorithms, including Logistic Regression, Random Forest, XGBoost, SVM, KNN, Decision Tree, and CatBoost, to analyze the marketing campaign target. Additionally, SHAP is used to visualize feature contributions and help explain model predictions.

Technologies: Python, Pandas, Streamlit, Plotly, Scikit-learn, XGBoost, CatBoost, SHAP, Matplotlib, Machine Learning.
